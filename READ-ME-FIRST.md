# Publish the local guide

The companion website is in C:/blend share/building-together-with-ai-agents.

## Before publishing

Choose the Git repository, visibility, and reuse license. Push the reviewed skill package through the chosen repository workflow. Set assets/config.js repositoryUrl to its HTTPS URL and sourceRevision to the tested commit or release.

Run the commands in README.md. Refresh evidence/results.json and assets/results.js from the generated reference/results.json. Keep the embedded dataset and downloadable evidence identical.

## Review the site

Open index.html locally. Review the five main sections, successful/stale/recovery examples, introductory and full scenario lists, keyboard navigation, copy controls, repository link, and narrow-screen layout. Confirm the configured repository is accessible to the intended audience.

The browser shows recorded Python results. Refresh those results after relevant source changes.

## Upload to Blend Share

Select the website folder so index.html is at the published root. Keep assets/, evidence/, and downloads/ adjacent to it. Choose the intended audience and discovery settings through the Blend Share interface.

After upload, check the five main sections, repository link, setup guide, and recorded evidence at the final URL.
